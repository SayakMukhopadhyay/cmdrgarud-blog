# cmdrgarud.blog

Provider-neutral static Astro migration of the former Ghost site. Content is validated Markdown, and the production build contains no client-side JavaScript.

## Commands

- `npm ci` — install the exact dependency versions from `package-lock.json`
- `npm run dev` — start the local development server
- `npm run check` — run Astro and TypeScript diagnostics
- `npm run build` — run diagnostics and create the static production build

Canonical URLs, feeds, sitemap, deployment workflows, and hosting adapters are intentionally deferred until the public routes and hosting provider are finalized.
